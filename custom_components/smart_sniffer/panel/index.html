Control Center

Agentic access

Everything the Control Center knows, as JSON for an AI assistant or a script. The guide at the end explains the fields.

Contains serial numbers, host names and addresses. Share it only with people and tools you trust.

Scripts and AI tools read the same JSON with a long-lived access token of an admin (your Home Assistant profile, Security): curl -H "Authorization: Bearer <token>" http://<ha>/api/smart_sniffer/agentic.json. Add ?fresh=1 to ask every agent first, ?download=1 to save it as a file.
